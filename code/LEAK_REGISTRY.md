# Leak Registry

Task 005 of the atomic execution checklist in
`spread-accuracy-roadmap` plan. This document lists every currently
confirmed leak/defect, the regression test that catches it, the artifacts it
affects, and its fix status. Update this file whenever a leak is fixed
(Rule 10/11: invalidate downstream caches/artifacts and record the fix here)
or a new leak is discovered (Rule 11: stop, add a failing test, record it
here, fix the root cause, then resume).

Status values: `confirmed` (test exists, root cause not yet fixed),
`fixed` (root cause fixed, regression test passes, caches invalidated),
`out_of_scope_this_phase` (confirmed but owned by a later phase per the task
brief — see "Testing scope" note in that phase's handoff).

## Notes on scope

This document is maintained by whichever phase is active. The rows marked
`out_of_scope_this_phase` are confirmed leaks named in the plan's "Immediate
trust assessment" section that belong to later phases (market snapshots/CLV,
validation/stacking) per this phase's explicit testing-scope restriction.
They are recorded here (Task 005 requires listing every currently confirmed
leak) but not fixed by this phase; the owning phase should update their
status when repaired.
